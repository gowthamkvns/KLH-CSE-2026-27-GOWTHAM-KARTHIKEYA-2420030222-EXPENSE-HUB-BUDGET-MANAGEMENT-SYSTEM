## 📖 Overview
ExpenseHub is a web-based application developed to simplify personal financial management and help users maintain organized records of their daily transactions[cite: 1]. The system provides a simple and organized approach to managing personal finances while demonstrating concepts related to software engineering, web development, database management, and data visualization[cite: 1].

📄 **[Read the full Project Abstract (PDF)](ABSTRACT.pdf)**

## ✨ Key Features
* **Transaction Tracking:** Record income and expenses along with details such as amount, date, category, payment method, and description[cite: 1].
* **Automated Calculations:** Automatically calculates total income, total expenses, and the available balance, reducing the effort required for manual record keeping[cite: 1].
* **Budget Management:** Define spending limits for different categories and monitor progress to keep track of whether expenses remain within planned limits[cite: 1].
* **Financial Overview:** Provides a centralized view of financial activities, making it easier to review transactions and identify spending patterns[cite: 1].
